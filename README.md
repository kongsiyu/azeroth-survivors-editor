# Azeroth Survivors Save Editor v1.4

Unofficial community save editor for Azeroth Survivors.

Features: visual talent editor (9 classes), 498-item Armory, progression through 12 zones, perk-reset controls, and unified save export.

## Use
Open the website, import your `.sav` file, edit your progression and export the modified save. Always back up your original save.

## Credits
Original talent editor: unknown community creator.
Armory, zone progression and integrations: Shilen.

## Hosting
This is a static site. To publish, open **Settings → Pages → Deploy from a branch → main → /(root)**.

Save editing is performed in the browser. Some styling references external Google Fonts.
