# 界面多语言（v1.6.1）

## 使用

页面顶部右侧可选择 **简体中文** 或 **English**。首次打开时按浏览器语言选择；后续使用本机保存的语言偏好。刷新页面仍保留语言。

覆盖导航、导入提示、职业、天赋名称和说明、装备、地图、成就点、印记、永久强化、导出状态、错误提示、弹窗、搜索占位文字和无障碍标签。移动端导航会换行显示语言选择。装备搜索同时接受中英文关键词，例如 `Common` 与“普通”。

切换时保留正在编辑的草稿和输入值。文件名、玩家名字、存档原文、游戏字段和 ID 保持原值；语言偏好不写入游戏存档。

## 维护

- `data/i18n.json`：语言定义、翻译词典、动态文案模板及旧文案别名。
- `src/i18n.js`：双向匹配、变量替换、语言偏好和动态界面同步。
- `src/i18n.css`：语言选择控件和移动端布局。
- `tools/build-resources.cjs`：将资源与语言模块一并嵌入单文件页面。

词典以英文原文为键，`translations.zh-CN` 为中文。历史资源页面仍有中文原文，模块通过反向匹配将其纳入相同语言系统。动态文案使用 `{count}`、`{name}` 等占位符；显示时保留数值，仅翻译文案和可识别的界面名称。

天赋翻译采用官方客户端中与编辑器相关的中英文数据子集，并手工补齐旧版本缺少的 4 个名称和 10 条说明。来源校验信息保存在词典元数据中。

现有天赋脚本经过混淆，因此语言层监听显示内容更新，不改动其序列化逻辑。`script`、`style`、存档原文、文本输入值、文件名和玩家名字不参与显示翻译。新增含用户原文的展示区域时，应标记 `data-i18n-ignore`。

新增第三种语言时，在 `locales` 中定义选项，并添加该语言的翻译词典和动态模板。缺少翻译时回退到英文。

重新生成页面：

```text
node tools/build-resources.cjs
```

## 验证

```text
node --test tests/resources.test.cjs tests/i18n.test.cjs
node tests/resources.browser.cjs <sample.sav>
node tests/i18n.browser.cjs <sample.sav>
```

浏览器检查包括语言自动选择、双向切换、刷新记忆、9 职业动态界面、天赋提示、错误校验文字、批量弹窗、装备双语搜索、低经验警告、草稿和原文保护、实际导出，以及桌面与窄屏布局。浏览器测试使用 Playwright 与 Edge；可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径。
